FLUJO DE PROCESO LOGÍSTICO - SISTEMA DE SHIPPING Y LOGÍSTICA
================================================================

1. FASE INICIAL: CREACIÓN Y GESTIÓN DE BOOKING
------------------------------------------------

1.1 Eventos de Inicio:
- Event: Nuevo Booking Creado
- S/M Contrato Asignado
- Event: Contacto con Procesos

1.2 Actores Involucrados:
- CSS / Oper. BD (Servicio al Cliente / Operaciones BD)
- Agente de Origen
- Ventas SL
- Empresas Representadas SEA
- Finanzas

1.3 Proceso de Creación de Booking:
a) Agente de Origen:
   - Recepción de Solicitud del Shipper - Nuevo Embarque
   - Crear nuevo Booking
   - Guardar Shipper's Informational eDocs
   - Notificar CSS y Ventas SL de Booking creado
   - Sugerir hacer la información del Booking
   - Confirmar CSO
   - Booking Asignado

b) CSS / Oper. BD:
   - Definir Service Level
   - Definir Fecha de Salida / Llegada
   - Verificar: ¿Es el día de Recepción Cliente Comercial?
   - Generar Quick Booking
   - Guardar Cliente Comercial / Datos de Embarque / Datos de eDocs
   - Asignar Contrato Booking Agente
   - Informar / Notificar de Booking Agente
   - Negociar Oferta con Cliente

c) Ventas SL:
   - Si es un Cliente Nuevo, validar si es un Cliente Comercial o Cliente
   - Luz verde del Cliente de Ventas
   - Enviar Shipping Instruction al Cliente Comercial (CSS)
   - Solicitar Booking

2. FASE DE PREPARACIÓN Y CONFIRMACIÓN
-------------------------------------

2.1 Eventos:
- Event: Booking Solicitado
- Event: Booking Confirmado
- Event: Data Out (DOC)
- Event: Número Contenedor Asignado

2.2 Proceso de Confirmación:
a) CSS / Oper. BD:
   - Revisar Booking Cliente Comercial
   - Recepcionar Pre-Alerta de Aduanas, etc.
   - Confirmar QBK - 48h CDN - BHP
   - Ingresar Datos Generales
   - Enviar Draft B/L al Agente
   - Informar Agente de Cambios
   - Informar Cliente próxima salida
   - Guardar Booking Confirmado (BKS)
   - Dirigir / Crear Schedule
   - Enviar Draft B/L

b) Agente de Origen:
   - Solicitar Booking a Carrier
   - Verificar: ¿Espacio Confirmado?
   - Si no: Rechazar Embarque (Evento Final)
   - Si sí: Cliente acepta informe
   - Filtro Comercial STZ-QBK-Pacta Vencimiento

3. FASE DE CARGA Y SALIDA
-------------------------

3.1 Eventos:
- Event: Freight Loaded (LCT)
- M: Draft B/L Enviado
- Event: Freight Departure (FCT)
- M: Pre Alerta + Notificación de B/L Guardados

3.2 Proceso de Carga:
a) CSS / Oper. BD:
   - Ingresar Datos Generales
   - Solicitar / Guardar Pre-Alerta del Agente
   - Disposicionar Pre-Alerta
   - Revisar Operaciones
   - Confirmar Zespe (ZPD)
   - Solicitar MBL (original)
   - Remitir MBL y DBL / Debit Note al Cliente de Origen
   - Guardar Debit Note en eDocs
   - Guardar B/L en eDocs
   - Guardar Pre-Alerta en eDocs
   - Confirmar Pre-Alerta
   - Notificación de MBL y B/L de CRUCE
   - Recepcionar Número de Tracking

NOTA IMPORTANTE: Condiciones y plazos para pre-alerta y documentación

4. FASE DE VENTA Y FACTURACIÓN
------------------------------

4.1 Eventos:
- M: Venta Pre-facturada
- M: Factura de Venta Guardada
- M: Notificación de Embarque Enviada
- M: B/L Master Enviado
- M: Transporte Asignado
- M: Transport Booking Creado

4.2 Proceso de Facturación:
a) CSS / Oper. BD:
   - Reasignar Tema al Vendedor(a)?
   - Feedback Vendedor(a)
   - Ingresar Costos Venta
   - Facturar al Cliente
   - Cambiar status a DEV
   - Cambiar status a RSA
   - Asignar Transporte / Vendedor-OMS
   - Notificación a Ventas?
   - Solicitar Venta Terrestre
   - Creación Transport Booking
   - Factura-Credit Factory
   - Enviar Notificación de Embarque al Cliente
   - Cargar MBL Universal al eDocs (MBLU)
   - Entregar Carpeta a Operaciones y Ops
   - Hacer Solicitud de Pago al Cliente Comercial (FSC)

b) Finanzas:
   - Solicitar Pago a Finanzas
   - Filtro Pagos reportados
   - Confirmar Pago
   - Filtro Confirmar y guardar Facturas
   - Guardar Facturas en eDocs
   - Procesar Cobros Nuevos?

5. FASE DE ARRIBO Y DESCONSOLIDACIÓN
-----------------------------------

5.1 Eventos:
- Event: Arribo (SCT)
- M: Aviso de Arribo Confirmado
- M: DUA Confirmada
- Event: Descarga (SCT)
- Event: Gate Out (SCT)
- M: Desconsolidación

5.2 Proceso de Arribo:
a) CSS / Oper. BD:
   - Confirmar Llegada (ETA)
   - Notificar al Transportista
   - Facturación de Desconsolidación de Contenedor
   - Transferencia Bancaria y Carga de B/L
   - Hacer Solicitud
   - Guardar HBL Consignado y DUA en eDocs
   - Subir Carga HBL a eDocs
   - Confirmar DUA
   - Notificar al Cliente de DUA Confirmada
   - Solicitar Pago de DUA
   - Confirmar Pago
   - Guardar DUA en eDocs
   - Entregar DUA al Cliente
   - Entregar Carga al Cliente

b) Finanzas:
   - Solicitar Pago a Finanzas
   - Emitir Carta de Responsabilidad (CDR) y Carga Adicional con Comprobante de Pago
   - Consultora a Hacienda por fechas de pago de impuestos y aduanas
   - Adjuntar facturas de venta
   - Filtro Pagos Proveedor
   - Confirmar Pago
   - Guardar Aviso de Arribo, Carta de Cliente (FCL y LCL)
   - Dar 'OK' para entregar documentación
   - Procesar Capital con TSL (Transporte) y Comisión de Docs a FSL

6. FASE FINAL: CIERRE Y DOCUMENTACIÓN
-------------------------------------

6.1 Eventos:
- Event: Devolución (SCT)
- M: Venta Terminada / Procesada

6.2 Proceso de Cierre:
a) CSS / Oper. BD:
   - Guardar Documentos (Facturas, B/L, etc.)
   - Ingresar Costos / Gastos
   - Facturar al Cliente Terrestre
   - Generar Orden de Pago con impuestos, arancel e intereses
   - Recuperar / Generar Factura del Proveedor a FSL
   - Solicitar Factura de Proveedor
   - Registrar Factura Proveedor
   - Filtro Pagar Transportista y Proveedor
   - Filtro Descuento de 3 meses (NO se acepta más facturas de costos)
   - Cerrar Tráfico + CSO (Evento Final)

ROLES Y RESPONSABILIDADES
=========================

1. CSS / Oper. BD (Servicio al Cliente / Operaciones BD):
   - Gestión principal del booking
   - Coordinación con agentes y clientes
   - Manejo de documentación
   - Facturación y cobros
   - Seguimiento operativo

2. Agente de Origen:
   - Creación inicial de booking
   - Coordinación con carriers
   - Gestión de espacio en buques
   - Confirmación de servicios

3. Ventas SL:
   - Validación de clientes
   - Aprobación comercial
   - Gestión de relaciones comerciales

4. Empresas Representadas SEA:
   - Representación de empresas asociadas
   - Coordinación interempresarial

5. Finanzas:
   - Gestión de pagos
   - Control de facturación
   - Procesamiento de cobros
   - Gestión de impuestos y aduanas

2. Filtros de Pago:
   - Pagos reportados
   - Confirmación de pagos
   - Pagos de proveedores

3. Filtros de Documentación:
   - Confirmación de DUA
   - Validación de B/L
   - Verificación de pre-alertas

4. Filtros de Cierre:
   - Descuento de 3 meses
   - Verificación de facturas pendientes

=======================

2. Documentos de Transporte:
   - Draft B/L
   - Master B/L (MBL)
   - House B/L (HBL)
   - Debit Note

3. Documentos de Aduanas:
   - Pre-Alerta
   - DUA (Declaración Única Aduanera)
   - Carta de Responsabilidad (CDR)

4. Documentos Financieros:
   - Facturas de Venta
   - Facturas de Proveedor
   - Comprobantes de Pago
   - Orden de Pago

TIEMPOS Y PLAZOS CRÍTICOS
=========================

1. Confirmación de Booking:
   - 48h CDN - BHP para confirmación

2. Pre-Alerta:
   - Plazos específicos según regulaciones

3. Documentación:
   - Tiempos de entrega de B/L
   - Plazos de DUA

4. Pagos:
   - Filtro de 3 meses para descuentos
   - Plazos de pago de impuestos

ESTADOS DEL PROCESO
===================

1. Estados de Booking:
   - DEV (Desarrollo)
   - RSA (Respuesta de Agente)

2. Estados de Documentación:
   - Pendiente
   - Confirmado
   - Guardado en eDocs

3. Estados de Pago:
   - Solicitado
   - Confirmado
   - Procesado

4. Estados Finales:
   - Cerrar Tráfico + CSO
   - Rechazar Embarque

Este flujo representa un sistema completo de gestión logística que abarca desde la creación inicial de un booking hasta la entrega final de la carga y el cierre financiero del proceso.
